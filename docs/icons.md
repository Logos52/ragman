# Icon pipeline

Every item gets one grid icon, generated by Grok from the product photo, in one locked style that copies EFT's inventory icons, then fitted to the item's footprint by a script. Nothing is drawn by hand. The avatar is the one exception and has its own style at the end of this page.

## Output spec

| Property | Value |
| --- | --- |
| File | `images/icons/<slug>.png` in ragman-data |
| Format | PNG, 8-bit RGBA, transparent background |
| Canvas | 128 px per cell: a 2x2 item is 256x256, a 4x3 item is 512x384, a 1x1 is 128x128 |
| Fill | the item's longest side spans 88% of the canvas; 6% padding each side |
| Orientation | unrotated footprint; the app rotates the image when the item is rotated |
| Source photo | `images/photos/<slug>.jpg`, the real product photo or a cropped screenshot |
| Prompt log | `images/icons/<slug>.prompt.txt`, the exact prompt used, so a redo is reproducible |

## Style lock

The same style block goes into every prompt, unchanged. It is what makes the grid read as one piece.

```
Realistic 3D product render of a single item in the style of an Escape from Tarkov inventory icon: physically accurate materials, matte finish, colors slightly desaturated, light honest wear but clean, no outline, no cartoon shading. Three-quarter view from slightly above unless the pose line says otherwise. Soft diffuse studio light from the upper left, gentle ambient occlusion in the creases, no hard shadows, no ground shadow, no reflections of a room. Centered on a pure white background. Item only: no person, no hands, no table, no props, no text, no watermark. Sharp focus, crisp edges, no blur, no depth-of-field.
```

## Per-category pose

Added after the style block. One line per category, fixed.

| Category | Pose line |
| --- | --- |
| tops | folded once, front facing, collar at the top, as a shop display fold |
| bottoms | folded in half lengthwise, waistband at the top |
| outerwear | folded once with the front showing, collar at the top |
| footwear | the pair side by side, viewed from the outer side, toes to the left |
| accessories | three-quarter view from slightly above, the whole object visible |
| electronics | top-down view, slightly angled, screens off and blank |
| bags and cubes | front view standing upright, straps tucked, slightly from above |
| consumables | the sealed packet or bottle front facing, label legible as shapes not text |

## Aspect line

The footprint sets the shape of the drawing, so the icon fills its cells instead of floating in them.

```
Composition fills a {W}:{H} frame, the object's longest axis running {horizontally | vertically}.
```

For a 4x3 MacBook: `fills a 4:3 frame, longest axis running horizontally`. For a 1x2 cable: `fills a 1:2 frame, longest axis running vertically`. For 1x1 and 2x2: `fills a square frame`.

## Reference image

Attach the product photo to the Grok prompt as the image input and add:

```
Use the attached photo as the exact reference for shape, color and details. Keep every real color. Do not add or remove parts.
```

For Machismo items the photo is on a model. Crop the screenshot to the garment before attaching, and add `Show the garment alone, off the body, folded as described.`

## Full prompt template

```
{style lock}
{pose line for the category}
Composition fills a {W}:{H} frame, the object's longest axis running {direction}.
Use the attached photo as the exact reference for shape, color and details. Keep every real color. Do not add or remove parts.
Subject: {official name}, {maker}.
```

Example, Anker 733, footprint 2x1:

```
Realistic 3D product render of a single item in the style of an Escape from Tarkov inventory icon: physically accurate materials, matte finish, colors slightly desaturated, light honest wear but clean, no outline, no cartoon shading. Three-quarter view from slightly above unless the pose line says otherwise. Soft diffuse studio light from the upper left, gentle ambient occlusion in the creases, no hard shadows, no ground shadow, no reflections of a room. Centered on a pure white background. Item only: no person, no hands, no table, no props, no text, no watermark. Sharp focus, crisp edges, no blur, no depth-of-field.
Top-down view, slightly angled, screens off and blank.
Composition fills a 2:1 frame, the object's longest axis running horizontally.
Use the attached photo as the exact reference for shape, color and details. Keep every real color. Do not add or remove parts.
Subject: Anker 733 Power Bank (GaNPrime PowerCore 65W), Anker.
```

## Post-processing

Grok does not return transparent PNGs, so every output goes through `scripts/icon-fit.py` (part of v1):

1. Remove the white background with rembg, alpha matting on.
2. Trim to the opaque bounding box.
3. Scale so the longest side is 88% of the footprint canvas, keeping aspect.
4. Center on a transparent canvas of `128*W` by `128*H`.
5. Save as `images/icons/<slug>.png` and write the prompt to `<slug>.prompt.txt`.
6. Also save a 56 px per cell preview for the approval step.

Run: `python scripts/icon-fit.py <slug> <grok-output.png> --footprint 2x1`.

## Acceptance

An icon is approved by Wedge before it replaces the grey placeholder. Reject and regenerate if any of these fail:

- The silhouette is readable at 56 px per cell on the dark grid.
- Colors match the real item. No invented colorways.
- Nothing extra: no hands, props, text, shadows, background remnants.
- The pose matches the category line.
- The object fills the frame; no small object floating in a big box.
- Lighting and angle match neighboring icons: same upper-left light, same three-quarter tilt, same matte finish.

Three rejections in a row on the same item: swap the reference photo for a cleaner one before trying again.

## Avatar

The figure on the left does not use the item style. It is the one Ghibli-style drawing in the app: `Flat cel-shaded illustration, Studio Ghibli inspired, matching the palette of the tsumugu.cc cast portraits: muted colors, soft two-tone shading, clean dark outline, pure white background. Full-length standing portrait, neutral relaxed pose, facing forward, arms at sides. Short dark hair, brown rectangular glasses, calm half smile, in the manner of the Shen Wen portrait on tsumugu.cc. Plain cream shirt and dark trousers, no bag, no accessories.` Canvas 512x1024, same post-processing, saved as `images/avatar.png`. One drawing for v1; equipped items show in the slot boxes, not on the body.
